# Облачное сохранение результатов «Читательского навигатора»

**Статус:** подготовлена схема защищённой базы. Сайт пока использует локальное хранение; до подключения проекта Supabase данные в облако не отправляются.

## Что будет сохраняться
- Учётная запись пользователя через Supabase Auth (email + пароль).
- Псевдоним ученика и класс.
- По каждому из восьми модулей: баллы (0–6), число проверенных заданий (0–4), ответы и время изменения.
- Доступ учителя к сводной таблице класса. Доступ ученика — исключительно к своим данным благодаря RLS.

## Подключение
1. Создать проект в https://supabase.com/dashboard (бесплатный план возможен при соблюдении ограничений).
2. В **SQL Editor** выполнить файл [schema.sql](schema.sql).
3. В **Authentication → Providers** разрешить вход по email. Для несовершеннолетних использовать школьные учётные записи или псевдонимы и соблюсти требования школы по обработке персональных данных.
4. Получить в **Project Settings → API Keys** только *publishable key* (начинается с `sb_publishable_`) и **Project URL** из настроек проекта.
5. Включить для учителя доступ по инструкции в конце schema.sql, после создания учётной записи учителя.
6. Подключить интерфейс приложения к этой базе и проверить запись и чтение на двух тестовых аккаунтах.

## Пробный отчёт
Файл `chitatelskiy_navigator_8_klass_rezultaty.csv` не импортируется, не включается в репозиторий и не переносится в базу. При подключении облака перенос локальных старых данных должен быть отключён по умолчанию.

## Безопасность
**Никогда** не отправляйте и не сохраняйте `service_role`, `sb_secret_...` или пароли в репозитории. Публичный publishable key допускается только при включённой и протестированной RLS. Таблица teacher_access пополняется только владельцем базы в SQL Editor.
